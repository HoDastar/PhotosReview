# Reclight Server

🚀 Backend service for the Reclight ecosystem.

## Features

- User login & token authentication
- Email verification
- Dictionary API service
- WebSocket secure communication
- MySQL database support

## Tech Stack

- Java 17
- Spring Boot
- MySQL
- Redis (optional)

## Run Locally

```bash
git clone https://github.com/yourname/ReclightServer.git
cd ReclightServer
./mvnw spring-boot:run
